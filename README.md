# Sudoku Game
Konsolowa gra Sudoku napisana w języku C

# Opis programu
Program implementuje grę Sudoku z rozszerzonymi funkcjami:
- Generowanie plansz w 3 rozmiarach: 4x4, 9x9 i 16x16
- 3 poziomy trudności
- System zapisu/ładowania stanu gry
- Statystyki rozgrywki (czas, liczba ruchów)
- Kolorowe wyróżnienie wprowadzonych liczb

# Funkcje
- Interaktywne menu główne
- Kolorowe oznaczenia:
  - Szare: oryginalne podpowiedzi
  - Niebieskie: liczby wprowadzone przez gracza
  - Kropki: puste pola
- System serializacji stanu gry
- Pomiar czasu gry
- Algorytm generujący poprawne plansze

# Wymagania
- Kompilator C (gcc, clang)
- Terminal wspierający kody ANSI
